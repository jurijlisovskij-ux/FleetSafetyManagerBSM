# Fleet Safety Manager Native Windows RC2

Изменения:

- исправлена рабочая директория Windows-службы;
- база `Data/fsm.db` и документы всегда создаются рядом с программой;
- добавлена автоматическая облачная сборка;
- формируются два Windows-установщика:
  - Office Setup;
  - Ship Setup;
- конечным пользователям не нужны Docker, PostgreSQL, Node.js или .NET SDK;
- установка создаёт Windows-службу и открывает порт 8080.

Ограничение RC2:

- Ship Edition пока использует ту же функциональную основу;
- выбор одного конкретного судна и `.fsmsync` появятся в Offline Sync RC1.
