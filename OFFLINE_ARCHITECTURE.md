# Offline Architecture

## Office
- центральная локальная база;
- все суда;
- импорт пакетов с судов.

## Ship
- локальная база одного судна;
- работа без интернета;
- локальные сертификаты и отчёты.

## Планируемый пакет

```text
MV_BALTIC_2026-07-12_001.fsmsync
├── manifest.json
├── equipment.json
├── deleted-items.json
├── documents/
│   ├── certificates/
│   └── reports/
└── checksums.json
```

## Основные правила

- пользователи и данные судна управляются офисом;
- оборудование имеет постоянный GUID;
- удаление передаётся как tombstone;
- один Package ID нельзя импортировать дважды;
- конфликт не перезаписывается молча.
