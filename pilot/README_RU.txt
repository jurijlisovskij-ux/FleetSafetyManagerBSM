FSM REMOTE PILOT — ТЕСТ БЕЗ ОБЛАЧНОГО АККАУНТА И ДОМЕНА

На компьютере Office:
1. Установите и запустите Fleet Safety Manager Office.
2. Распакуйте этот архив полностью.
3. Запустите Start-FSM-Remote-Pilot.cmd.
4. Выберите судно из списка.
5. Рядом с распакованным пакетом появится и автоматически откроется
   персональная папка FSM_Ship_ИМЯ_СУДНА_Pilot.
6. Для другого судна снова запустите Start-FSM-Remote-Pilot.cmd и выберите его.
   Все судовые пакеты будут использовать один действующий защищённый адрес.
7. Не выключайте Office-компьютер во время теста.

На удалённом компьютере Ship:
1. Передайте на этот компьютер всю персональную папку судна.
2. Дважды нажмите Install FSM Ship Pilot.cmd.
3. В информационном окне FSM нажмите OK.
4. В запросе Windows нажмите Да / Yes. Если Windows попросит пароль
   администратора компьютера, введите его.

Установка, настройка, активация и первая синхронизация выполняются автоматически.

После теста запустите Stop-FSM-Remote-Pilot.cmd на Office-компьютере.

ВАЖНО:
- настройки роутера, VPN, домен и облачный аккаунт не требуются;
- разрешение администратора Windows требуется один раз для установки службы;
- соединение зашифровано HTTPS;
- временный адрес действует, пока работает туннель;
- если Office-компьютер или туннель перезапустить, временный адрес изменится;
  нужно заново создать и передать персональные папки судов;
- этот пилот предназначен только для проверки. Для эксплуатации 40 судов
  будет использоваться постоянный FSM Cloud Server.
