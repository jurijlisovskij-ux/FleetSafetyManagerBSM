FSM REMOTE PILOT — ТЕСТ БЕЗ ОБЛАЧНОГО АККАУНТА И ДОМЕНА

На компьютере Office:
1. Установите и запустите Fleet Safety Manager Office.
2. Распакуйте этот архив полностью.
3. Запустите RemotePilot\Start-FSM-Remote-Pilot.cmd.
4. На рабочем столе появится папка FSM_Ship_Pilot_Connection.
5. Не выключайте Office-компьютер во время теста.

На удалённом компьютере Ship:
1. Установите FleetSafetyManager_Ship_Setup.exe.
2. Передайте на этот компьютер всю папку FSM_Ship_Pilot_Connection.
3. Нажмите правой кнопкой на Connect Ship to FSM Pilot.cmd и выберите «Запуск от имени администратора».
4. Откройте FSM Ship, выберите судно и введите одноразовый Activation Code.

После теста запустите Stop-FSM-Remote-Pilot.cmd на Office-компьютере.

ВАЖНО:
- настройки роутера, VPN, домен и облачный аккаунт не требуются;
- соединение зашифровано HTTPS;
- временный адрес действует, пока работает туннель;
- после перезапуска туннеля нужно передать новую папку подключения;
- пилот предназначен только для проверки; для постоянной эксплуатации будет использоваться FSM Cloud Server.
